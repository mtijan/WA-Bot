3.4 Entity Relationship Diagram (ERD) #

Menggambarkan 16 entitas basis data SQLite3 secara logis dan fisik. Gambar ERD historis belum memuat tabel suppression independen opt_out_contacts; data dictionary di halaman ini adalah acuan schema terbaru.

Tabel 3.4 -- Daftar Relasi, Kardinalitas, dan Integritas Referensial Antar-Tabel
Tabel IndukRelasiTabel AnakDeskripsi

sessions1 --o{ NcampaignsSatu sesi menginisiasi banyak kampanye
sessions1 --o{ Nchatbot_flowsSatu sesi memiliki banyak alur chatbot

campaigns1 --o{ Ndelivery_logsSatu kampanye terdiri dari banyak log pengiriman

warmer_campaigns1 --o{ Nwarmer_logsSatu kampanye warmer mencatat banyak log (Cascade Delete)

Tabel sessions

Tabel 3.5.1 -- Kamus Data Fisik Tabel sessions (Instance WhatsApp Sesi)
Nama KolomTipe DataConstraintsKegunaan
session_idVARCHAR(50)PRIMARY KEYIdentitas unik instance WA (ex: wa-finance-1)
phone_numberVARCHAR(20)NULLDisimpan setelah handshake sukses
statusVARCHAR(15)NOT NULLEnum: CONNECTED, DISCONNECTED
proxy_urlTEXTNULLAlamat proxy URL opsional untuk routing sesi
proxy_idINTEGERFOREIGN KEYID referensi ke tabel proxies
created_atDATETIMEDEFAULT CURRENT_TIMESTAMPWaktu sesi pertama kali dibuat

Tabel chatbot_flows

Tabel 3.5.5 -- Kamus Data Fisik Tabel chatbot_flows (Struktur Alur Chatbot Interaktif)
