Telegram Alert Baseline #

Repositori ini menyediakan script alert ringan untuk staging ketika monitoring stack penuh belum terinstal. Script ini memeriksa kesiapan API, worker, ketersediaan URL publik, penggunaan disk, dan kesegaran backup terenkripsi. Jika terjadi kegagalan, script akan mengirimkan notifikasi ke Telegram atau webhook eksternal.

cd /opt/wa-bot/backend npm run monitor:alert
Variabel Env yang Dibutuhkan
VariabelTujuan / Deskripsi
WA_BOT_ALERT_TELEGRAM_BOT_TOKENToken bot Telegram. Harus dirahasiakan dan jangan dicommit.
WA_BOT_ALERT_TELEGRAM_CHAT_IDID Chat Telegram tujuan. Harus dirahasiakan dan jangan dicommit.
WA_BOT_ALERT_WEBHOOK_URLWebhook eksternal opsional. Harus dirahasiakan dan jangan dicommit.
WA_BOT_ALERT_PUBLIC_URLURL frontend publik opsional (contoh: https://stagingwabot.web.id/).
WA_BOT_ALERT_PUBLIC_HEALTH_URLURL health publik opsional (contoh: https://stagingwabot.web.id/health).
WA_BOT_ALERT_BACKUP_MAX_AGE_HOURSBatas usia backup sebelum dianggap stale. Default: 36.
WA_BOT_ALERT_DISK_WARN_PERCENTBatas peringatan penggunaan disk. Default: 80.

Pasang script ini sebagai timer systemd menggunakan panduan di docs/deploy/EXTERNAL_ALERTING.commands.md.

Resource Thresholds (Netdata) #

Netdata dipasang secara native pada host (tanpa Docker) untuk memantau sumber daya sistem (CPU, RAM, Disk, dan Network IO). Dashboard Netdata diikat ke localhost (127.0.0.1:19999) demi keamanan, dan diakses dari komputer lokal menggunakan SSH Tunneling:

ssh -L 18181:127.0.0.1:19999 ubuntu@43.157.224.57

Setelah tunnel aktif, akses di komputer lokal melalui: http://localhost:18181/.

Health Queries SQLite #

Query SQLite untuk investigasi manual atau integrasi ke alert script di masa depan.

Sesi Terputus:

SELECT session_id, phone_number, status FROM sessions WHERE status != 'CONNECTED';

Campaign Macet:

SELECT id, name, session_id, status, created_at FROM campaigns WHERE status = 'RUNNING' AND datetime(created_at) < datetime('now', '-30 minutes');

Warmer Melebihi Durasi:

SELECT id, name, status, started_at, duration FROM warmer_campaigns WHERE status = 'RUNNING' AND datetime(started_at, '+' || duration || ' minutes') < datetime('now');
